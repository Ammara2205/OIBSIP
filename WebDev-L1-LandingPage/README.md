Musafir Cafe — Landing Page

About the Project

Musafir Cafe is a travel-inspired cafe landing page designed for travellers and explorers. The website presents the cafe's identity, introduces its concept, and provides simple navigation for visitors.

Features

- Navigation bar with Home, About, and Contact links
- Hero section with a cafe introduction
- Multiple content sections
- Consistent colours and typography
- Responsive layout for different screen sizes
- Footer with contact information or links

Technologies Used

- HTML5
- CSS3
